EXECUTIVE SUMMARY
================================================================================

This repository was developed with assistance from two AI tools throughout its
development lifecycle (March 2025 - March 2026):

1. ChatGPT (OpenAI) - Used continuously for ad-hoc troubleshooting and debugging
2. Claude Code (Anthropic) - Used systematically from January 2026 onwards for
   feature development, refactoring, and documentation

All core scientific methodology, statistical procedures, and data cleaning logic
were designed and implemented by the human research team. AI tools were used
exclusively to assist with code implementation, debugging, and technical
infrastructure development.
