PROTOCOL DECISIONS:
-------------------

1. FILE NUMBERING CONVENTION
   Decision: Use sequential integer numbering for all scripts in c_scripts/3_standardize/
   Rationale: Avoid decimal numbering (e.g., 08.5) which can create confusion and looks unprofessional
   Implementation: When adding new datasets, renumber all affected scripts to maintain sequential order
   Example: If adding script between 08 and 09, renumber:
            - Old 08 stays 08
            - New script becomes 09
            - Old 09 becomes 10
            - Old 10 becomes 11
            - etc.
